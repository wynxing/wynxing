## 项目 / Projects

### [Veil](https://github.com/wynxing/Veil) · Rust

按物理屏保持 Windows 显示器关闭，直到主动恢复。  
Keeps selected Windows displays off until you turn them back on.

### [Lanwork](https://github.com/wynxing/Lanwork) · Rust

Windows 11 上的桌面搜索条和面板：应用、文件、待办、便签。  
A Windows 11 search bar and panel for apps, files, todos, and notes.

### [MayDolist](https://github.com/wynxing/MayDolist) · Rust

本地优先的行动收件箱，把待办、便签和 GitHub 上下文放在一起。  
A local-first inbox for todos, notes, and GitHub follow-ups.

### [online](https://github.com/wynxing/online) · Rust, Tauri

桌面实时双语同传：采集系统音频，在窗口或浮动层显示字幕。  
Real-time bilingual interpretation from system audio, with floating subtitles.

### [agent-flight-recorder](https://github.com/wynxing/agent-flight-recorder) · Python

录制 Agent 的运行，再回放、对比，并把失败收成回归用例。  
Records an agent run, replays it, and turns the failure into a regression case.

### [paper-evidence-agent](https://github.com/wynxing/paper-evidence-agent) · Python

旨在核对一条论断和指定引文之间的证据关系，并给出可定位的原文依据。  
Aims to check a claim against the cited paper and point at the supporting passage.
